QAOA MaxCut

Color every node of a graph one of two colors so that as many edges as possible join different colors. That is the MaxCut problem. The Quantum Approximate Optimization Algorithm (QAOA) tackles it with alternating layers of two operations, each set by an angle: γ rewards cut edges and β mixes the candidate answers.
